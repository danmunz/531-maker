# Rules for Assigning Accessory Lifts

Each session has one main 5/3/1 lift and two supersets of accessories: Superset A (1a/1b) and Superset B (2a/2b).

1. If the workout includes Squat or Deadlift, then use Superset B for core or single-leg/hamstring work.
2. If the workout includes Deadlift, then avoid extra heavy posterior-chain or lower-back loading.
3. If the workout includes Squat, then avoid adding a lot of extra bilateral leg fatigue.
4. If the workout includes Bench Press or Overhead Press, then use Superset A for pulling work.
5. If the workout includes a lot of pressing, then make pull volume at least equal to push volume.
6. For normal training weeks, keep assistance to two two-exercise supersets: Superset A = 1 pull + 1 push-or-arms; Superset B = 1 core-or-single-leg/hamstring + 1 complementary lower-body or core movement.
7. If Bench Press is the primary 5/3/1 lift, then make the push-or-arms slot in Superset A a chest push by default.
8. If Overhead Press is the primary 5/3/1 lift, then use the push-or-arms slot in Superset A for triceps or shoulder-balance work, and consider extra upper-back or rear-delt work.
9. If a main lift already heavily trains a muscle group, then do not pile on another heavy barbell accessory for that same area.
10. If an accessory can support the main lift with less fatigue, then prefer that option.
11. If a movement pattern is missing from the workout, then use accessories to fill the gap.
12. If the workout is lower-body heavy (Squat or Deadlift), then make Superset B core plus a lighter single-leg/hamstring movement.
13. Across a four-week block, repeat the same accessory slot pattern for each day type, but rotate only a small pool of exercises in each slot so progression stays easy to track.
14. In deload week, reduce assistance to one superset only: 1 pull + 1 core or light lower-body movement, for 2 to 3 easy sets each.
15. If choosing between two accessory options, then pick the one that helps the main lift; improves push/pull balance; adds muscle; and creates less recovery cost.
